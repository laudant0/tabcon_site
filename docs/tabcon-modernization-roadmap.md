# TABCON Site Modernization Roadmap

## Vision
Transform the current static institutional website into a scalable TypeScript-powered infrastructure platform.

---

## Phase 1 — Foundation Cleanup

### Mobile Navigation
- Add responsive hamburger menu
- Create mobile sidebar/dropdown navigation
- Improve mobile spacing and typography
- Ensure navigation works across all pages

### Asset Migration
- Move externally linked images into local assets folder
- Organize images by category:
  - hero
  - projects
  - partners
  - leadership
- Optimize image sizes and formats

### UI Refinement
- Improve responsiveness
- Reduce repetitive layout structures
- Standardize spacing and typography
- Improve button consistency

---

## Phase 2 — TypeScript Migration

### Recommended Stack
- Next.js
- TypeScript
- TailwindCSS

### Component Architecture
/components
  Header.tsx
  Footer.tsx
  Hero.tsx
  Navigation.tsx
  ProjectCard.tsx

### Benefits
- Better scalability
- Easier maintenance
- Cleaner architecture
- Faster future feature development
